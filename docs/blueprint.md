# **App Name**: AttendAI

## Core Features:

- Hero Section: Full-width hero section with a prominent title and clear tagline to immediately capture user attention.
- AI Attendance Verification: Facial recognition and processing via AI, acting as a tool to provide accurate data with reasoning on student attendance.
- Live Analytics Charts: Interactive, visually appealing charts (using Recharts/Chart.js) on the 'Demo' page to show real-time attendance analytics.
- Student Attendance Details: Display student details in an organized table with their pictures, name and attendance record.
- Attendance Success Indicators: Clear indicators (icons and/or color-coding) in tables and charts, that distinguish successful attendance.
- Call to Action Buttons: Visually distinct, interactive buttons for actions like "View Demo" or "Explore Features" that show hover effects with color change and subtle shadow.
- Responsive Layout: Ensure site renders well and is easy to use on mobile, tablet and desktop screen sizes.

## Style Guidelines:

- Primary color: A vibrant, attention-getting blue (#3F51B5) to represent the themes of trust and technology.
- Background color: Light gray (#F0F2F5), offering a professional and clean look while keeping the attention focused on content.
- Accent color: A more saturated and brighter violet (#7E57C2) draws attention to interactive elements, and provides enough contrast.
- Headings font: 'Poppins' (sans-serif) for a clean and modern look.
- Body text font: 'PT Sans' (sans-serif), easy to read, will not distract from data or headlines.
- CCTV icons, AI/face recognition graphics and color-coding will indicate verification status clearly.
- Grid-based layout using card components for features, outcomes, and team sections.
